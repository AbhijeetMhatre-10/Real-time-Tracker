# 🚀 Real-Time Location Tracking App

## 📝 Description / Overview
This is a **Real-Time Location Tracking Application** built using **Node.js, Express, Socket.io, and Leaflet.js**.  
It allows multiple users to share their current locations live on a map. Each user's location is tracked in real-time, and markers are automatically updated as users move.  

This project can be extended for applications like fleet tracking, delivery tracking, or live location sharing.

---

## ⚙️ Installation

1. **Clone the repository**
```bash
git clone https://github.com/your-username/live-tracking-app.git
cd live-tracking-app
```

2. **Install dependencies**
```bash
npm install
```

3. **Run the server**
```bash
node app.js
```

4. **Open your browser**
```bash
http://localhost:3000
```

## ✨ Features

* Real-time location tracking for multiple users
* Live map view using Leaflet.js
* Automatic marker update for moving users
* Handles user disconnects by removing markers
* Lightweight and easy to deploy

## 🛠️ Technologies Used

* Node.js – Backend runtime
* Express.js – Web framework
* Socket.io – Real-time communication
* Leaflet.js – Interactive maps
* EJS – Templating enging
* OpenStreetMap – Map tiles
